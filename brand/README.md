## Brand Color Palette

| Token | Hex | Usage |
|---|---|---|
| Primary Green | `#15803D` | Primary actions, active indicators, emblem primary |
| Dark Green | `#14532D` | Wordmark text (`KURUMBAR`), high-contrast headings on yellow |
| Golden Yellow | `#FACC15` | Brand accent, highlights (pair only with `#14532D` or `#1E293B` text; never white text) |
| Background | `#FAFAF5` | Warm off-white page surface |
| White | `#FFFFFF` | Card and emblem clean background |
